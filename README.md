# Informe mensual · Fábrica de Producción UIDE

Página pública del informe mensual (sin nombres).

- `index.html`: la página que publica GitHub Pages.
- `template.html`: plantilla sin datos (Claude la usa para generar `index.html`).
- `data.json`: datos de todos los meses (sin nombres). Cada mes se agrega uno nuevo.

Actualización: cada mes Claude entrega un `index.html` nuevo; se reemplaza el archivo en este repositorio.
